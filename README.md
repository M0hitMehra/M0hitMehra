### 🤖 Internal AI Tooling Platform — MCP Server

Designed and developed a full-stack Model Context Protocol server from the ground up.

**Tech Stack:** Python, FastAPI, LangChain, React, TypeScript, MongoDB, JWT, SSE

- Built an AI integration platform enabling secure communication between AI tools and client applications.
- Implemented Server-Sent Events (SSE) to replace inefficient polling with real-time streaming.
- Designed high-throughput client-server communication with graceful error handling.
- Owned end-to-end architecture and backend implementation.
- Integrated the platform into engineering workflows to enable AI-assisted operations across teams.
